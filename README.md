# Student Management System (3 Roles)

**Team Members:** Marmik & Manan  
**Tech Stack:** Python (Basic File Handling, JSON, Loops, Functions)  
**Project Duration:** 7 Days Mini Project  

## Project Files
1. `main.py` — Main entry point & Student Portal (Marmik)
2. `teacher_module.py` — Teacher Portal: view, search, update marks & topper check (Manan)
3. `admin_module.py` — Admin Portal & JSON `load_data()` / `save_data()` functions (Marmik & Manan)
4. `students.json` — Local JSON database file (pre-loaded with 3 sample records so it never starts empty)

## How to Run
1. Open terminal inside the `Student_Management_System` folder.
2. Run:
   ```bash
   python main.py
   ```
